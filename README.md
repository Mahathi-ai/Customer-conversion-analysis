# Customer Conversion Analysis using Python

## Overview

This project analyzes customer conversion data from a bank marketing campaign using Python and Pandas.

The project focuses on understanding customer conversion patterns and identifying factors related to customer subscription.

## Dataset

The dataset is the Bank Marketing dataset from the UCI Machine Learning Repository.

It contains information about customers contacted during a bank marketing campaign.

## Tools Used

- Python
- Pandas
- Matplotlib

## Analysis Performed

- Dataset size and column inspection
- Missing value checking
- Duplicate value checking
- Overall customer conversion rate
- Conversion rate by job
- Conversion rate by number of campaign contacts
- Customer conversion visualization

## Key Finding

The overall customer conversion rate in the dataset is approximately **11.69%**.
